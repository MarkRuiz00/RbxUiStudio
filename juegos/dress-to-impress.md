# Dress to Impress

**Genre:** fashion / social competition · **Style family:** [cartoony](../estilos/cartoony.md) (brand shapes) ·
**Why:** the reference for theme-driven UI where every shape carries the brand.

The lesson: **a branded shape (the heart) can replace standard controls** — as long as it stays where players expect it.

## Visual language

| | Observed |
|---|---|
| Palette | Pink (`#F598DC`, `#EE7ECA`) + lavender + white. Everything — frames, buttons, currency — stays in this family. |
| Buttons | **Circles** with a pink gradient and a glossy icon, in a left and a right column. |
| Window | Pink frame with frilly/lace edges and bows; title with arrow navigation (`◀ 1/2: Pants ▶`). |
| Tabs | White pills with pink text (`Wheel`, `Palette`, `Patterns`). |
| Close | **A big heart with an X**, bottom-center of the window. |
| Currency | Bottom-left: star icon + yellow pill `221`, heart icon + pink pill `526`. |
| Round info | Top-center `Theme: Internet Famous` + timer in a thin elegant font. |
| Gamepasses | A **circular** popup with three passes and the heart close. |

## Steal this

- One brand shape reused for close, currency and popups.
- Theme + timer top-center makes the round structure obvious.

## Avoid

- Moving the close button is risky: Dress to Impress compensates by making it huge and heart-shaped.
  If your shape is less obvious, keep close top-right.

# Brookhaven RP

**Genre:** social roleplay · **Style family:** [minimal](../estilos/minimal.md) (light) ·
**Why:** the most visited Roblox experience ever (tens of billions of visits); ~497–526K concurrent in mid-2026.

The lesson: **for the youngest audience, icons beat words** and translucent light-gray squares never clash with the world.

## Visual language

| | Observed |
|---|---|
| Buttons | Light gray squares (`#C4C4C2`) at ~30 % transparency, big pictogram, no label on the right column. |
| Pickers | Grid of square tiles: circular colored icon + one word (`Police`, `Bank`, `S.W.A.T.`). |
| Close | Big red X tile (`#A5241D`) in the same tile grid. |
| Clock | Gray pill `5:20 PM / Monday` top-left next to the Roblox buttons. |
| Welcome | Huge thin uppercase title `BROOKHAVEN` on a translucent white plate, `Play` button, update notes card. |
| Purchase | Dark-gray modal "Insufficient Funds" with Cancel / Buy Robux — looks like Roblox's own prompt. |
| Font | Thin/regular clean sans (Gotham/Builder look). |

## Steal this

- A right-edge column of 6 pictogram buttons covers avatar, edit, bag, character, vehicles, houses.
- Neutral translucent UI makes a colorful world the star.

## Avoid

- Thin fonts below ~16 px on phones; Brookhaven gets away with it because labels are optional.

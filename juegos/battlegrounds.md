# The Strongest Battlegrounds · Jujutsu Shenanigans

**Genre:** anime fighting · **Style family:** topbar-native minimal ·
**Why:** Jujutsu Shenanigans was ~178K concurrent in June 2026; TSB set the template for the genre.

The lesson: **extend Roblox's own top bar** (same height, same dark translucent pills) instead of building a second bar.

## Visual language

| | Observed |
|---|---|
| Top bar | Dark translucent rounded pills next to Roblox's buttons: `Characters`, shop `$5`, settings, emotes — they look like part of Roblox's UI. |
| Moves | 4 slots bottom-center: number on top, move name in small text; the slot flashes red while active. |
| Character | Name in italic serif caps above an ultimate bar (`SERIOUS MODE`, `King of Curses`). |
| Mobile | Right side: circular translucent buttons (block, dash, special, punch, jump). |
| Health | Small thin green bar top-right. |

## Steal this

- Match the Roblox top bar row (pill height, transparency, spacing) when you add buttons up there.
  ⚠️ Roblox doesn't document exact topbar metrics — measure in Studio's device emulator.
- Move names under numbers: players learn the keys while playing.

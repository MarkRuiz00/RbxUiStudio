# DOORS

**Genre:** horror · **Style family:** diegetic [minimal](../estilos/minimal.md) ·
**Why:** the reference for horror UI on Roblox.

The lesson: **remove almost everything.** What remains is small, warm-colored and placed at the edges.

## Visual language

| | Observed |
|---|---|
| Colors | Cream strokes (`#F8DEBF`) on dark brown translucent fills (`#3A241D`) — the hotel's own palette. |
| Hotbar | 3 rounded squares with thin cream stroke, a number in a small circle on the top-left corner, `x1` count bottom-right. |
| Stamina | Thin cream-outlined pill bottom-left. |
| Currencies | Top-right, tiny: icon + number (revives, knobs). |
| Mobile | One big round crouch button with a cream ring. |
| Crosshair | A single small dot. |

## Steal this

- Take UI colors **from the environment** so the HUD feels part of the world.
- Number badges on slots double as keybind hints.

## Avoid

- Pure white UI in horror: it breaks the darkness. Use off-white/cream at partial transparency.
